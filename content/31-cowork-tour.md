# Cowork Tour: Folders, Sub-agents & Schedules

Let's walk the Cowork workspace so nothing surprises you in the lab. Open **Claude Desktop** and click **Cowork** in the sidebar.

:::note If you don't have Cowork
No paid plan or not seeing it yet? Read along — you'll still understand every concept, and you can run the lab whenever you get access. (Cowork is a **research preview**, so the exact screens may change over time.)
:::

## The pieces you'll see

### 1. The folder / workspace you grant
Cowork works inside folder(s) **you choose**. When you start, you'll point it at a directory (e.g., a project folder on your desktop). That's its working area — it reads and writes there.

:::warning This is the big mental shift
In chat, Claude can only see what you paste/upload. In Cowork, it can **see and change the files in the folder you grant.** Powerful, and the reason we start on copies.
:::

### 2. The task box
Instead of "ask a question," you'll "describe an outcome." Cowork typically shows you a **plan** of steps before or as it works, so you can follow along and intervene.

### 3. Sub-agents (working in parallel)
For larger jobs, Cowork spawns **subagents** to handle parts simultaneously — one organizing files while another writes a summary. You'll see this activity in the interface. It's mostly automatic; you just benefit from the speed.

### 4. Scheduled tasks
You can save a task and have Claude **run it automatically on a cadence** (e.g., every Monday at 8am). Scheduled tasks run through the desktop app, so behavior can depend on your machine being on. This is unique to Cowork (regular chats can't do it). Think: a recurring "draft our weekly update" job.

### 5. Projects (in Cowork)
Group related tasks into a **persistent workspace** with its own files, links, instructions, and memory. Open the project later and Claude already has the context. Perfect for recurring or long-running work.

### 6. Claude in Chrome (optional pairing)
Install the **Claude in Chrome** extension and Cowork can act on websites — navigate, click, fill forms, pull info. Great when a task needs the web, not just local files.

## Scavenger hunt

In your Cowork view, locate:

- [ ] Where you **choose/grant a folder** for Cowork to work in
- [ ] The **task input** (where you describe the outcome)
- [ ] Any indication of a **plan / steps** Claude will take
- [ ] Where **scheduled tasks** are created or listed
- [ ] **Projects** in Cowork
- [ ] *(Optional)* the **Claude in Chrome** extension page, if you want web tasks later

:::concept How this connects to Module 3
Everything you learned plugs in here: **Connectors** give Cowork access to Jira/Drive/etc.; **Skills** teach it your task formats; **Plugins** bundle those; and **subagents** are Cowork dividing the work. Cowork is where all the power-ups come together.
:::

## A safe-start checklist

Before the lab, set yourself up to experiment fearlessly:

- [ ] I'll create a **dedicated practice folder** (not my real project files)
- [ ] I'll put **copies** of any real documents in it
- [ ] I understand Cowork can **modify files** in the folder I grant
- [ ] I'll **read the plan** Claude proposes before letting it run wild on anything important
