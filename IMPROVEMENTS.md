### Anthropic's own best-practice guidance (teachable content)
From [Best practices for getting started with Claude Cowork](https://claude.com/blog/best-practices-for-getting-started-with-claude-cowork):
- **Five-ingredient checklist** for a good Cowork task: multiple inputs; a file deliverable; recurring; clear quality bar; boring middle steps (extract/compile/reconcile).
- **"Make Claude ask you questions before it starts"** — the single highest-leverage briefing tip.
- Chat vs Cowork rule: Chat for questions/brainstorming, Cowork for handing off finished work products.
- Verify fast by knowing the output shape beforehand ("you already know what good looks like").

From [Anthropic's marketing ops team on Cowork](https://claude.com/blog/how-anthropics-marketing-operations-team-uses-claude-cowork-to-automate-reporting-and-campaign-builds):
- Weekly metrics report: scheduled Sunday-evening task + prep skill + **proofreading skill that checks every number against a verified source** + action-items skill pushing to Asana. Two days → two hours.
- Campaign ops: Slack intake channel processed hourly by a **dispatcher skill**; event-build skill; **separate audit skill** (fresh Claude instance does a test registration before anything ships); manager agent diagnoses failures.
- Advice: turn repeated corrections into skills; **build the proofreading skill first**; ask Claude to reflect on how it interpreted instructions; lean on scheduled tasks.

### Known limitations & gotchas trainers should teach
- **Connector truncation**: connectors often pull only the first few hundred/thousand rows — work on local/exported files for complete datasets. ([9x review](https://go9x.com/blog/claude-cowork-review))
- **Confident wrong numbers**: "Claude will occasionally present wrong numbers with complete confidence" — every figure must trace to a source. ([Elevation Capital finance playbook](https://ai.elevationcapital.com/blogs/claude-cowork-for-finance))
- **No cross-session memory of past Cowork projects** — reusability comes from saved files, skills, and Projects, not from "Claude remembers." ([techtiff](https://techtiff.substack.com/p/claude-cowork-explained))
- **Desktop scheduled tasks require app open/awake**; the Aug 2026 remote/cloud execution beta removes this — worth teaching both states. ([9x review](https://go9x.com/blog/claude-cowork-review), [support.claude.com](https://support.claude.com/en/articles/12138966-release-notes))
- **Shared usage limits** (5-hour rolling + weekly, shared with Chat/Code) — budget lab time; a known bug can show spurious "rate limit reached" needing a support reset. ([betterclaw.io](https://www.betterclaw.io/blog/claude-cowork-rate-limit-reached))
- **Safety**: Anthropic itself warns of potentially destructive file actions and prompt injection from web content — teach folder-scoping and the permission prompts. ([TechRadar](https://www.techradar.com/pro/anthropics-new-cowork-tool-offers-claude-coding-help-to-non-experts))
- **The core skill gap is briefing + verifying, not tech**: "people who treat it like a chatbot get mediocre results; people who learn to brief and verify get the hours back." ([9x review](https://go9x.com/blog/claude-cowork-review))
- **Model selection matters for finance-grade work**: Opus for new/complex decomposition, Sonnet for stable repeated tasks; chain sequential prompts rather than one mega-prompt — multi-step inference is where numeric errors emerge. ([Elevation Capital](https://ai.elevationcapital.com/blogs/claude-cowork-for-finance))
- Rollout literature: appoint an owner, run a champion-based pilot (2-3 workflows per team, weekly 20-min check-ins), train on use cases not features, 30/60/90-day roadmap. ([claudeimplementation.com](https://claudeimplementation.com/blog/claude-training), [Enterprise DNA](https://enterprisedna.co/resources/blog/how-to-train-your-team-on-claude/))

## B. Corrections / updates the existing course likely needs

1. **Add the Finance lane** — the biggest gap, and the best-supported role: Anthropic ships a finance plugin, ten finance agent templates on paid plans, and the Excel add-in is GA for Pro. Sources in A.
2. **Cowork is no longer desktop-only**: web + mobile + remote cloud sessions (Aug 2026 beta) and the Chrome side panel now runs full Cowork sessions. If the course says "desktop app, Mac" or teaches Chrome as "research only," update it — Chrome is now a full Cowork surface with skills/connectors, and sessions hand off across devices. ([claude.com/blog/cowork-chrome-side-panel](https://claude.com/blog/cowork-chrome-side-panel))
3. **Scheduled tasks**: teach the new reality — with remote execution, schedules run with no device online; on desktop-local they still require the app open. ([support.claude.com](https://support.claude.com/en/articles/12138966-release-notes))
4. **Teach the official role plugins** (sales, marketing, product-management, finance) as the fast path before custom skills — each lane's lab can start "install the plugin, run the command, then customize." ([claude.com/plugins/*](https://claude.com/plugins/sales))
5. **Add the five-ingredient task checklist and "make Claude ask questions first"** to the briefing module — both from Anthropic's own best-practices post. ([claude.com blog](https://claude.com/blog/best-practices-for-getting-started-with-claude-cowork))
6. **Upgrade the verification module** with the Anthropic-internal patterns: a proofreading skill that traces every number to a verified source, and a separate audit agent with fresh context that tests the deliverable end-to-end. ([marketing ops blog](https://claude.com/blog/how-anthropics-marketing-operations-team-uses-claude-cowork-to-automate-reporting-and-campaign-builds))
7. **Add a limits-and-gotchas page**: connector row truncation (prefer exported files for full datasets), shared usage caps, no cross-project memory, prompt-injection caution on web content, confident-wrong-numbers. Sources in A.
8. **Distinguish enterprise-only from everyone**: FactSet/S&P/Moody's/LSEG-class connectors and Compliance/Analytics APIs are enterprise; the finance plugin, agent templates, Excel add-in, and file-based workflows are on normal paid plans. ([anthropic.com/news/advancing-claude-for-financial-services](https://www.anthropic.com/news/advancing-claude-for-financial-services))
9. **Rollout module**: align with champion/pilot/owner/30-60-90 patterns; train on the team's own three use cases, not features. ([claudeimplementation.com](https://claudeimplementation.com/blog/claude-training))

## C. Per-role improvement proposals

Each play lists: deliverable, Cowork features exercised, and a source showing it is a real working use case.

### C1. Finance (new lane — 6 plays)

1. **Month-end variance pack (flagship lab).** Input: budget vs actuals xlsx (provide a sample workbook). Prompt: break down variances by GL code and vendor, top-5 positive/negative deltas, waterfall, CFO-ready narrative of what changed and what needs attention. Deliverable: xlsx + one-page commentary. Features: file reading, multi-sheet analysis, `/variance-analysis` from the finance plugin. Sources: [Elevation Capital playbook](https://ai.elevationcapital.com/blogs/claude-cowork-for-finance), [finance plugin](https://claude.com/plugins/finance), [aiforcfo.com workflow](https://www.aiforcfo.com/post/how-to-use-claude-financial-analysis).
2. **Three-way reconciliation with exception report.** Payment/settlement report + bank statement + order/invoice book; match by ID; flag mismatches, missing settlements, fee discrepancies, duplicates; color-coded exception xlsx with financial impact. Features: multi-source matching, live-formula xlsx output, `/reconciliation`. Source: [Elevation Capital](https://ai.elevationcapital.com/blogs/claude-cowork-for-finance).
3. **Debtors-ageing chase emails.** Ageing xlsx → tone-graded drafts (friendly 1–30d, firm 31–60d, escalation 61–90d, final 90+d) saved as Gmail/Outlook drafts, never sent. Features: connector write (drafts), conditional logic, verification-before-sending discipline. Source: [Elevation Capital](https://ai.elevationcapital.com/blogs/claude-cowork-for-finance).
4. **Driver-based 12-month forecast.** Decompose P&L into levers, build an Assumptions sheet, project 12 months with every line formula-driven; teach Opus-for-complex + chained prompts. Deliverable: multi-sheet live-formula xlsx. Source: [Elevation Capital](https://ai.elevationcapital.com/blogs/claude-cowork-for-finance), [Claude for Excel capabilities](https://www.agensi.io/learn/claude-for-excel).
5. **Board-pack draft via Excel→PowerPoint handoff.** Take the variance model and produce a board/leadership deck where numbers trace to the model; exercises the Excel↔PowerPoint context handoff (or Cowork xlsx→pptx). Sources: [VentureBeat](https://venturebeat.com/technology/anthropic-rolls-out-claude-ai-for-finance-integrates-with-excel-to-rival), [nerova.ai](https://nerova.ai/use-cases/claude-for-financial-services-explained-anthropic-finance-agents-2026).
6. **Month-end closer template + proofreading skill (capstone).** Run Anthropic's Month-end closer agent template (close checklist, journal entries, close report), then build a proofreading skill that traces every figure to source — and state the accountability rule: "the person who reviews and posts the entries is responsible." Sources: [anthropic.com/news/finance-agents](https://www.anthropic.com/news/finance-agents), [marketing ops proofreading pattern](https://claude.com/blog/how-anthropics-marketing-operations-team-uses-claude-cowork-to-automate-reporting-and-campaign-builds), [Elevation Capital](https://ai.elevationcapital.com/blogs/claude-cowork-for-finance).

### C2. Product managers (4 plays)

1. **PRD from the plugin, then critique it.** `/write-spec` on a real problem statement; lab twist: have Claude interview the PM first ("ask me questions before starting"). Features: PM plugin, question-first briefing. Sources: [PM plugin](https://claude.com/plugins/product-management), [best-practices blog](https://claude.com/blog/best-practices-for-getting-started-with-claude-cowork).
2. **Competitor teardown with Chrome side panel.** Use Cowork-in-Chrome to walk competitor sites/docs/pricing pages, then `/competitive-brief`; deliverable: battlecard-style doc + comparison xlsx. Features: browser actions, skills in browser, file output. Sources: [claude.com/blog/cowork-chrome-side-panel](https://claude.com/blog/cowork-chrome-side-panel), [PM plugin](https://claude.com/plugins/product-management).
3. **Discovery synthesis at scale.** Folder of interview notes/survey exports → `/synthesize-research` → structured insights doc with per-claim traceability back to the source note (verification tie-in). Sources: [PM plugin](https://claude.com/plugins/product-management), [Enterpret guide](https://www.enterpret.com/blog/claude-skills-for-product-managers-the-complete-guide).
4. **Weekly stakeholder update on a schedule.** Jira/tracker connector + `/roadmap-update` + `/stakeholder-update` variants per audience (exec / engineering / customer), scheduled weekly with remote execution. Sources: [PM plugin](https://claude.com/plugins/product-management), [support.claude.com scheduling](https://support.claude.com/en/articles/12138966-release-notes). The "spec → roadmap → competitive → update in one afternoon" loop is documented at [Snyk's PM skills article](https://snyk.io/articles/7-claude-skills-product-managers/).

### C3. Sales (4 plays)

1. **Pipeline review + weighted forecast.** CRM export or connector → `/pipeline-review` (stale deals, risks, weekly action plan) and `/forecast` (best/likely/worst). Deliverable: xlsx + action list. Source: [sales plugin](https://claude.com/plugins/sales).
2. **Call summary → CRM-ready follow-up.** Paste a transcript → `/call-summary` → action items + draft follow-up email as a draft only. Source: [sales plugin](https://claude.com/plugins/sales).
3. **Account research → personalized outreach batch.** Research each target account (Chrome/web), find pain points, draft personalized outreach; emphasize human review before send. Sources: [sales plugin auto skills](https://claude.com/plugins/sales), [GrowthSpree ABM walkthrough](https://www.growthspreeofficial.com/blogs/account-based-marketing-claude-ai-guide), [SyncGTM](https://syncgtm.com/blog/best-claude-skills-for-b2b-sales).
4. **Daily briefing schedule.** Scheduled morning task: unread email + Slack + pipeline alerts → short bucketed brief. Sources: [sales plugin](https://claude.com/plugins/sales), [best-practices blog daily-briefing example](https://claude.com/blog/best-practices-for-getting-started-with-claude-cowork).

### C4. Marketing (4 plays)

1. **Weekly performance report the Anthropic way.** Rebuild Ian Chan's workflow small: scheduled Sunday task reads last week's report + ad-platform/GSC data + Slack, outputs metrics + focus areas; then add the proofreading skill. Deliverable: report + leadership slides. Source: [marketing ops blog](https://claude.com/blog/how-anthropics-marketing-operations-team-uses-claude-cowork-to-automate-reporting-and-campaign-builds).
2. **Campaign plan + brand-checked content batch.** `/campaign-plan` → `/draft-content` for 3 assets → `/brand-review` against an uploaded style guide (configure brand voice in local settings). Source: [marketing plugin](https://claude.com/plugins/marketing).
3. **Budget pacing dashboard.** Pull spend across ad platforms into a live dashboard artifact with automatic pacing calculations. Source: [best-practices blog](https://claude.com/blog/best-practices-for-getting-started-with-claude-cowork), [Coupler.io roundup](https://blog.coupler.io/claude-cowork-for-marketing/).
4. **Nurture sequence + SEO audit.** `/email-sequence` for a persona and `/seo-audit` on the team's own site (Ahrefs/GSC connector or Chrome). Source: [marketing plugin](https://claude.com/plugins/marketing).
